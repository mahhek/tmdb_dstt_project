# Movie Revenue Prediction and Commercial Performance Analysis

## About the Project

This project focuses on predicting movie revenue and analysing the factors that may influence a movie's commercial performance. The data was collected from **The Movie Database (TMDB) API** and covers movies released between 2000 and 2025.

The project uses data preprocessing, exploratory data analysis, feature engineering, and machine learning techniques to study the relationship between movie characteristics and revenue.

## Dataset

The dataset contains **4,583 movie records** collected through the TMDB API.

It includes information such as:

- Movie budget and revenue
- Release date and runtime
- Genres and original language
- Production countries and companies
- Directors, writers, and cast
- Movie keywords and spoken languages

After data cleaning and preprocessing, the dataset was prepared for further analysis and machine learning.

## Project Objectives

- Collect movie data using the TMDB API.
- Clean and prepare the collected data.
- Explore patterns in movie revenue and other movie characteristics.
- Identify features that may influence commercial performance.
- Develop regression models to predict movie revenue.
- Evaluate and compare model performance.
